# GitHub activity: sources, styling, and refreshes

This repository is the GitHub profile README. The separately hosted portfolio
website is outside this change.

## What was making the streak look stuck?

The original `README.md` embedded an SVG from
`https://streak-stats.demolab.com/?user=khaled-amireh` with styling and
`timezone=Asia/Amman` query parameters. No streak numbers were hardcoded in
the README. The third-party service fetches contribution calendars from
GitHub's GraphQL API and computes the streak.

Two cache layers can delay that image:

- The service's [file cache](https://github.com/DenverCoder1/github-readme-streak-stats/blob/main/src/cache.php)
  has a 24-hour lifetime. Its [generator](https://github.com/DenverCoder1/github-readme-streak-stats/blob/main/src/generator.php)
  sometimes refreshes stale streaks earlier, but same-day contribution totals
  can still come from the cached data.
- The [image endpoint](https://github.com/DenverCoder1/github-readme-streak-stats/blob/main/src/index.php)
  sends `Cache-Control: public, max-age=86400`. This was also observed on an
  actual response on October 31, 2026. Browsers and image proxies may reuse it.

A random URL parameter can bypass an image cache but does not clear the
provider's underlying data cache. Neither cache can make contributions appear
before GitHub has processed them. GitHub documents an additional delay of up to
24 hours in [troubleshooting missing contributions](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/troubleshooting-missing-contributions).
These are confirmed delay mechanisms; the previous image alone does not reveal
which cache held a particular viewer's stale result.

`github-metrics.svg` is a different, committed snapshot generated by
`.github/workflows/metrics.yml` daily at 03:00 Amman time. It includes a
contribution calendar and its own half-year commit-streak statistics. The snake
SVGs are generated every 12 hours on the `output` branch by `snake.yml`.
Neither is currently embedded in the README. Their snapshot schedule and streak
definitions can differ from the streak card. No saved counts were edited here.
GitHub's native contribution graph below the README is controlled by GitHub;
README styles cannot recolor that graph.

## Current streak implementation

- The same 495 × 195 card now loads from `assets/github-streak.svg`.
- `.github/workflows/streak.yml` runs the pinned official generator directly on
  a fresh Actions runner with caching explicitly disabled. It queries GitHub
  rather than requesting the publicly hosted SVG. The job reuses the existing
  `METRICS_TOKEN` secret when available, with `github.token` as a fallback.
- Refreshes are scheduled at minute 17 every four hours (03:17, 07:17, 11:17,
  15:17, 19:17, and 23:17 in Asia/Amman). Actions schedules can run late.
  `workflow_dispatch` permits a manual refresh. The first push of the workflow
  to `main` also triggers a refresh.
- `scripts/update_streak.py` validates a temporary SVG before replacing the
  published card and updating the README's visible retrieval time in Amman.
  Missing files, provider error pages, incomplete cards, and missing README
  markers fail the job before a commit. The previous image and time stay visible.
- A genuine zero streak is accepted. No fallback streak numbers are generated.
- The checked-in starting card was retrieved from the public provider on
  October 31, 2026; it may include the provider's cached data. The caption says
  **retrieved**, not that GitHub's underlying data was updated at that moment.
  Subsequent successful Actions runs replace it with direct GitHub results.

The workflow starts operating after these changes are pushed to `main`.
No workflow was run or changes published as part of the local edit. If the
retrieval time stops advancing, check **Actions → Refresh GitHub streak** for
token, API, validation, or branch-write errors. A protected `main` branch must
permit the configured Actions bot to write these snapshots.

## Blue palette

The streak ring uses `#3B82F6`, its border uses `#2563EB`, and the flame and
current-streak label use `#60A5FA`. Navy `#0B1220`, white `#F1F5F9`, and slate
text keep the dark card readable. SVG animations are disabled on the streak.

The hero's neural lines, node highlights, faint glow, underline, and typing
cursors share this palette. Geometry, timing, and reduced-motion alternatives
are preserved. Metrics CSS and the snake generator's explicit palettes apply
the same blues to generated contribution cells so later refreshes retain the
theme. Existing metrics data and language-specific colors are preserved.


The tests cover failed/incomplete refreshes, unchanged data bytes, real zero
values, timestamp conversion, and preservation of the rest of the README.
